Tailscale과 Windows App으로 사무실 PC 원격접속하기

양쪽 Tailscale 연결부터 Windows App의 PC 추가와 로그인까지. 설정 화면과 2분 46초 영상으로 따라 하는 원격접속 실습입니다.

Hoon Kim·2026년 10월 16일

오늘 교육은 Tailscale과 Windows App으로 사무실 Windows PC에 원격 접속하는 방법을 다룹니다. Tailscale로 두 기기를 연결한 뒤, Windows App에서 사무실 PC의 화면을 엽니다.

교육 영상

강사의 설명과 함께 보거나, 필요한 설정 화면에서 멈춰 따라 할 수 있는 2분 46초 무음 영상입니다. 화면은 공식 문서를 바탕으로 만든 교육용 재구성입니다. 표시된 기기명·IP·계정은 예시입니다.

교육 영상 다운로드 · MP4

실습 전에 준비할 것

  • 접속받을 사무실 PC: Windows Pro·Enterprise·Education, 전원과 인터넷 연결. Windows Home은 기본 원격 데스크톱의 접속 대상이 될 수 없습니다.
  • 접속할 기기: Windows PC 또는 Mac. Tailscale과 Windows App을 설치합니다.
  • 사용 권한: 회사 장비는 담당자의 승인을 받고 설정합니다. 접속할 Windows 계정과 암호를 준비합니다.

1. 사무실 PC에서 원격 데스크톱 켜기

사무실 PC에서 설정 → 시스템 → 원격 데스크톱으로 이동합니다. 원격 데스크톱을 켜고 확인합니다. 접속할 계정의 권한과 전원 연결 중 절전 설정을 확인합니다. 네트워크 수준 인증(NLA)과 방화벽 보호는 유지합니다.

2. 양쪽 기기를 Tailscale로 연결하기

  1. Tailscale 다운로드에서 각 기기에 맞는 앱을 설치합니다.
  2. 앱의 Log in을 선택하고 브라우저에서 인증합니다.
  3. 본인의 두 기기가 같은 tailnet에 연결됐는지 확인합니다. tailnet은 Tailscale의 사설 연결망입니다.
  4. 관리 콘솔의 Machines에서 접속받을 사무실 PC를 찾습니다. 그 PC의 100.x.x.x 주소를 복사합니다.

조직에서는 각자 초대된 계정과 허용된 접근 정책을 사용합니다. 계정 암호를 공유하지 않습니다. 재부팅 후 Windows 로그인 전에도 연결이 필요하면 사무실 PC의 Tailscale에서 Preferences → Run Unattended 사용 여부를 담당자와 확인합니다.

3. Windows App에 PC 추가하기

Windows App은 접속할 기기에서 실행합니다.

접속할 기기 PC 추가 경로
Windows Devices → Add(+) → PC 추가 창
Mac Devices → +(더하기) → Add PC

PC Name에 앞에서 복사한 사무실 PC의 Tailscale IP를 입력합니다. Add를 누르고 추가된 PC 카드를 엽니다. Windows에서는 Add & Connect로 바로 연결할 수도 있습니다. 앱 버전과 언어에 따라 메뉴가 다를 수 있습니다.

4. Windows 계정으로 로그인하기

접속 대상 PC의 Windows 계정과 암호를 사용합니다. Tailscale 로그인 계정과 구분합니다. 로컬 계정의 입력 예시는 OFFICE-PC\trainee입니다. 실제로는 본인의 PC 이름과 사용자 이름을 입력합니다. Microsoft 계정이나 도메인 계정은 지정된 계정 형식을 확인합니다.

Windows Hello PIN 대신 Windows 계정의 암호를 사용합니다. 인증서 경고가 나타나면 접속 대상 PC의 정보를 확인합니다. 예상과 다른 대상이면 중단하고 담당자에게 확인합니다.

5. 외부망에서 실습 결과 확인하기

휴대폰 핫스폿 등 외부 네트워크에서 접속합니다. 사무실 PC 화면이 열리고 마우스와 키보드로 조작할 수 있으면 기본 실습을 마친 것입니다.

접속이 안 되면 다음 순서로 확인합니다.

  1. 사무실 PC의 전원·절전 상태와 인터넷 연결
  2. 양쪽 Tailscale 연결·기기 승인·접근 권한
  3. Tailscale IP·원격 데스크톱 허용·Windows 에디션
  4. Windows 계정·암호·원격 접속 권한

공유기에서 3389 포트를 인터넷에 개방할 필요는 없습니다. 조직의 접근 정책과 Windows 방화벽은 통신을 허용해야 합니다. 방화벽 전체를 끄지 말고 담당자와 확인합니다.
