# Homepage webfonts

Self-hosted, unmodified WOFF2 font files. No system-wide font installation.

- Maru Buri Regular 400 / SemiBold 600: NAVER official webfont distribution. `MaruBuri-LICENSE.txt` contains the NAVER license notice and full terms.
- Pretendard Variable v1.3.9: official dynamic unicode-range subsets; CSS URLs rewritten to local files, binary fonts unmodified. See `Pretendard-LICENSE.txt`.
- `sources.json`: upstream URLs, sizes and SHA-256 hashes for update/removal. Font updates are manual and must retain licenses.
- Use: large hero Maru Buri 600; other headings Maru Buri 400; body/menu Pretendard Variable. Latin brand remains in its previous serif family.
- Remove: revert the typography commit or remove font links and restore CSS font stacks before removing this directory.
